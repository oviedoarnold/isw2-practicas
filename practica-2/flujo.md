Diferencias entre GitFlow y Trunk-based



GitFlow es un modelo de trabajo que utiliza diferentes ramas para organizar el desarrollo.

Normalmente incluye ramas como main, develop, feature, release y hotfix.

Cada nueva funcionalidad se desarrolla en una rama independiente.

Los cambios pasan por varias etapas antes de integrarse en la rama principal.

Esto brinda mayor control, aunque también puede aumentar la complejidad del proyecto.
